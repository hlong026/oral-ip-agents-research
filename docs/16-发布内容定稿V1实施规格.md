# 发布内容定稿 V1 实施规格

## 1. 目标

在视频合成与自动发布之间增加独立的“发布内容定稿”环节，统一管理：

- 无字幕干净母版
- 可编辑字幕及样式
- 发布标题
- 封面底图和模板
- 视频标签

定稿完成后生成不可变的发布内容版本。发布流程只接收该版本 ID、平台、账号和发布时间，不再接收可被篡改的视频、封面、标题或标签。

## 2. 业务边界

### 2.1 发布内容定稿

负责视频、字幕、标题、封面和标签的编辑、草稿保存、定稿渲染及版本管理。

### 2.2 发布执行

负责选择平台、账号和发布时间，并将已定稿内容提交给自动发布或人工发布包流程。

发布执行不得修改定稿内容。

## 3. 核心对象

新增 `PublicationRevision`，页面名称为“发布内容版本”。

```text
PipelineTask
  -> PublicationRevision(draft)
  -> PipelineRenderVersion
  -> PublicationRevision(finalized)
  -> PublishJob
```

状态：

- `draft`：可编辑草稿
- `rendering`：正在生成定稿成片
- `finalized`：已定稿，不可修改
- `superseded`：已被新定稿版本替代

草稿使用 `draftRevision` 乐观锁。旧版本提交必须返回冲突，不能覆盖新内容。

## 4. 内容数据

```json
{
  "schemaVersion": 1,
  "title": "发布标题",
  "topics": ["标签1", "标签2"],
  "subtitles": {
    "enabled": true,
    "source": "asr_aligned",
    "segments": [
      {
        "id": "segment-1",
        "startMs": 0,
        "endMs": 1800,
        "text": "可编辑字幕"
      }
    ],
    "style": {
      "fontFamily": "Noto Sans CJK SC",
      "fontSize": 48,
      "color": "#FFFFFF",
      "stroke": 3,
      "xPercent": 50,
      "yPercent": 82
    }
  },
  "cover": {
    "selectedFrameMs": 1500,
    "template": "bold-bottom"
  }
}
```

P0 字体白名单：

- `Noto Sans CJK SC`
- `Source Han Sans SC`
- `PingFang SC`

P0 字幕位置为全局位置，不支持单条字幕独立拖动。

## 5. 用户流程

1. 数字人视频生成后，合成步骤只生成无字幕干净母版。
2. 用户进入视频剪辑页，系统创建或恢复发布内容草稿。
3. 系统使用已有语音对齐结果生成字幕段落；用户可修改文本、字体、字号、颜色、描边和全局位置。
4. 系统生成 3 个标题候选和 5 至 8 个标签候选；AI 失败时允许完全手工编辑。
5. 系统从视频前 3 秒生成候选帧；用户选择一张底图和一个预设模板。
6. 页面自动保存草稿。
7. 用户点击“定稿”，系统从干净母版生成新成片和封面。
8. 质量检查和积分结算成功后，原子激活新成片并将内容版本标记为 `finalized`。
9. 发布页只读取已定稿版本，用户选择平台、账号和发布时间后创建发布任务。

## 6. 接口

```text
GET  /pipelines/{taskId}/publication-draft
PUT  /pipelines/{taskId}/publication-draft
POST /pipelines/{taskId}/metadata-suggestions
GET  /pipelines/{taskId}/cover-candidates
POST /pipelines/{taskId}/finalize
GET  /pipelines/{taskId}/publication-revisions
POST /publish/jobs
```

发布任务主入参：

```json
{
  "publicationRevisionId": "revision-id",
  "platforms": ["douyin"],
  "accountIds": {
    "douyin": "account-id"
  },
  "publishAt": null
}
```

服务端必须从已定稿版本读取标题、标签、视频和封面。旧客户端字段在过渡期可以保留，但不能覆盖新版本内容。

## 7. 不变量

- 字幕不得在初始视频合成阶段烧录。
- 没有干净母版的旧字幕成片不得再次烧录字幕。
- 已定稿版本不可修改；修改必须产生新草稿。
- 定稿重复请求不得重复扣费或重复创建渲染版本。
- 定稿失败必须保留草稿和旧活动成片。
- 发布任务必须固定到一个已定稿版本。
- 已开始发布的任务不得修改标题、标签、视频或封面。
- 同一平台存在多个可用账号时必须明确选择账号；只有一个账号时可自动选择。
- 发布结果未知时不得自动重试。

## 8. P0 范围

- 字幕生成、逐段文本编辑、全局拖动、字体选择
- AI 标题建议及手工修改
- AI 标签建议及手工修改
- 前 3 秒候选帧和预设封面模板
- 草稿自动保存和并发冲突保护
- 定稿渲染、失败保旧和版本固定
- 标题、封面、标签传递到自动发布或人工发布包
- 单账号自动选择、多账号明确选择

## 9. 非 P0

- 视频裁剪和删除片段
- 卡拉 OK 逐字字幕
- 单条字幕独立位置
- 自定义字体上传
- 智能关键帧评分和人物抠图
- 完整多轨时间线
- 多平台差异化标题和标签
- 封面 A/B 测试

## 10. 验收

1. 初始合成成片无字幕，并保存干净母版。
2. 字幕文本、字体和拖动位置与定稿 MP4 一致。
3. AI 建议失败时仍可手工完成定稿。
4. 封面底图来自视频前 3 秒。
5. 同一请求重复定稿只生成一个版本。
6. 旧草稿版本保存返回冲突。
7. 渲染失败不切换活动成片。
8. 发布任务使用指定的已定稿版本。
9. 人工发布包包含视频、封面、标题和标签。
10. 多账号场景不会误用其他账号。
11. 旧成片缺少干净母版时不会产生双字幕。
