## 1. 现状盘点与缺口

### 1.1 前端现状（EditorPage.tsx）

| 模块     | 现状                                    | 问题                                                           |
| -------- | --------------------------------------- | -------------------------------------------------------------- |
| 字幕样式 | 字号 32–64 / 4 色 / 3 档位置 / 描边滑杆 | 无字体选择、无关键词高亮、无动画、无背景条；预览为单行叠加文本 |
| 字幕校对 | 文案按标点切 8 行只读展示               | 不可编辑、无时间轴、与真实 ASR 词级时间戳脱节                  |
| BGM      | 三模式 + 音量滑杆                       | 曲库无实体，音量参数后端未消费                                 |
| 封面     | A/B/C 三候选（B/C 为占位文案）          | 无封面编辑能力、无平台画幅适配、候选实际只有首帧               |
| 画幅     | 固定 9:16 预览                          | 后端已支持 16:9 / 1:1，前端未暴露                              |

### 1.2 后端现状（FFmpegCompose · server/app/providers/real.py）

- ✅ 已支持：9:16(1080×1920) / 16:9(1920×1080) / 1:1(1080×1080) 三画幅、ASS 硬字幕、Logo 角标 overlay、BGM amix 混音、H.264/AAC、封面取成片首帧、质检报告。
- ❌ 缺口一：`_build_ass()` 样式**写死**（Arial 54px 白字），`ComposeInput.subtitle_style` 传入后未被消费——前端所有字幕配置目前是"假开关"。
- ❌ 缺口二：BGM 音量固定 `volume=0.12`，无 sidechain 闪避；`bgm_volume` 参数未落地。
- ❌ 缺口三：封面 = `-frames:v 1` 首帧截图，无标题层/角标层合成，无平台多尺寸导出。

**结论：本方案的技术主线 = 把前端已有的"配置意图"真正打穿到 FFmpeg 合成层，再向上补齐封面/字幕两大编辑系统。**

## 2. 竞品分析

| 竞品             | 核心实践                                                                                                       | 对本项目的启示                                                               |
| ---------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 剪映 / CapCut    | ①「智能划重点」：AI 提取字幕关键词自动套花字高亮；②卡拉OK逐字着色；③字幕样式模板库（花字/气泡/背景条一键套用） | 字幕系统按「预设优先、参数兜底」设计：先选模板再微调，而非从零调参           |
| Descript         | 文本即时间线：删除文稿文字 = 删除对应视频片段                                                                  | 字幕校对区升级为「文本驱动剪辑」入口：口播场景天然具备词级时间戳，删行即裁片 |
| Opus Clip        | 长视频→竖屏切片，自动重构图 + 一键多平台发布                                                                   | 封面/画幅按"一次设计、多平台导出"建模，发布前按平台自动裁切                  |
| 一帧秒创（秒创） | 模板化生产：字幕样式、封面版式、BGM 打包为可复用模板                                                           | 与现有「模板中心」打通：剪辑台的任何调整可一键"存为模板"                     |
| 度加剪辑（百度） | 口播场景专用：文稿快剪 + AI 封面标题推荐                                                                       | 封面标题直接从文案钩子句自动生成 3 候选，减少输入成本                        |

**竞品共识（5 条落地原则）**

1. 预设 > 参数：用户先挑"样式卡"，高级参数折叠在二级。
2. 所见即所得：任何配置改动 ≤100ms 反映在预览层（前端 CSS/Canvas 模拟，不等服务端）。
3. 文本驱动：口播视频的剪辑主轴是文稿，不是时间线；时间线是辅助可视化。
4. 平台意识前置：画幅/封面/安全区在剪辑阶段就按目标平台约束，而非发布时才发现裁切事故。
5. 模板沉淀：单次调整可复用（存为模板 → 下次任务自动套用）。

## 3. 封面设计系统

### 3.1 平台画幅矩阵（设计基准）

| 平台   | 视频画幅          | 封面比例                       | 推荐尺寸  | 关键约束                                                   |
| ------ | ----------------- | ------------------------------ | --------- | ---------------------------------------------------------- |
| 抖音   | 9:16              | 9:16（信息流）                 | 1080×1920 | 主页九宫格按 **3:4 中心裁切**——核心内容必须落在 3:4 安全区 |
| 小红书 | 竖 3:4 / 横 4:3   | **3:4 首选**                   | 1080×1440 | 双列瀑布流，标题大字决定点击率；横版 4:3 为 1440×1080      |
| 视频号 | 横 16:9 / 竖 9:16 | 横 1080×608 / 竖 6:7 1080×1260 | —         | 朋友圈分享卡为 1:1 中心裁切                                |
| B站    | 16:9              | 16:9                           | 1920×1080 | 首页推荐位小图，标题字号需 ≥ 画面高度 12%                  |
| 快手   | 9:16              | 9:16                           | 1080×1920 | 双列 feed 按 3:4 裁切，同抖音安全区策略                    |

### 3.2 核心设计：一次设计，多画幅导出

封面不按平台各做一张，而是**分层建模 + 安全区约束**，一份配置渲染出全部画幅：

```
CoverSpec {
  base:    "frame" | "upload" | "avatar"   // 底图：成片帧 / 上传图 / 数字人形象照
  frameAt: number                          // 底图=成片帧时的取帧时间点
  overlay: { color, opacity }              // 遮罩层（压暗提字）
  title:   { text, font, size, color, strokeColor, strokeWidth,
             align, maxLines }             // 标题层（钩子大字）
  badge:   { ipLogoKey, position }         // IP 角标层
  sticker: { text, style } | null          // 贴片层（"省2万""避坑"等强化贴）
  anchor:  "center" | "upper" | "lower"    // 构图锚点
}
```

**横竖屏差异化规则（渲染引擎内置，用户无感）**

- 竖屏（9:16 / 3:4 / 6:7）：标题置于**上 1/3**，人物置于下 2/3，角标右上；
- 横屏（16:9 / 4:3）：标题**左对齐居左半屏**，人物居右半屏，角标右下；
- 所有画幅共享同一 `CoverSpec`，仅由 `RatioLayout` 查表决定标题字号系数、锚点偏移与裁切窗口；
- 抖音/快手 9:16 封面额外绘制 3:4 安全区参考线，标题强制收进安全区。

### 3.3 封面模板（预制 5 款，与模板中心打通）

| 模板     | 版式                                   | 适用               |
| -------- | -------------------------------------- | ------------------ |
| 大字标题 | 压暗底图 + 3 行内超大粗体 + 关键词换色 | 政策解读、干货科普 |
| 人物特写 | 数字人半身像 + 侧边竖排标题 + 名字角标 | 人设向 IP          |
| 对比数字 | 左右分屏 + 巨型数字（"2万→0"）         | 省钱/收益/效率对比 |
| 黄黑警示 | 黄底黑字斜切条 + 感叹图形              | 避坑、风险提示     |
| 课程章节 | 统一底版 + 第 N 讲编号 + 进度条        | 系列课程           |

模板即 `CoverSpec` 预填值；用户选模板 → 改标题文字 → 完成。AI 依据文案钩子句自动生成 3 条候选标题（度加实践）。

### 3.4 技术实现

**渲染链路：前端 Canvas 预览 + 服务端 Pillow 定稿（双端同构 spec）**

1. 前端：`CoverSpec` → Canvas 2D 实时渲染（<16ms），画幅切换即重排；导出预览用 `canvas.toDataURL`。
2. 服务端定稿（保证与发布物一致）：
   - 取帧：`ffmpeg -ss {frameAt} -frames:v 1`（复用现有封面链路）；
   - 合成：Pillow 按 `CoverSpec` + `RatioLayout` 绘制遮罩/标题/角标/贴片，逐平台尺寸输出 `cover_{ratio}.jpg`；
   - 存储：沿用 `save_bytes("compose", ...)`，任务 artifacts 增加 `cover_keys: {ratio: key}`（对齐产物双层结构约定）。
3. 发布模块按目标平台从 `cover_keys` 取对应画幅，不再统一用首帧。
4. 字体：内置思源黑体 / 阿里巴巴普惠体等可商用字体，随镜像打包，Pillow 与 ffmpeg fontsdir 共用同一字体目录。

**接口增量**

- 剪辑修改统一提交到版本化重合成接口，封面参数由 "A/B/C" 升级为 `CoverSpec` JSON；
- 新增 `GET /pipeline/{id}/cover-candidates`：返回 AI 标题 3 候选 + 推荐取帧点（首帧/最大人脸帧/钩子句时间点）。

### 3.5 封面自动匹配链路（标题 × 底图 × 模板全自动）

**对标结论（2026-07 调研核实）**：必剪「封面模板一键爆款 + 智能抠图」做得最好；剪映是「帧选择器 + 模板 + 文字槽位」三步交互范式；阿里云视频智能封面证明「美学评分智能选帧」已是成熟能力；YouTube 的「自动 3 候选供挑选」是最优交互。共同公式：**封面 = 视频帧底图 + 预设模板槽位 + 自动填充文字，用户只做微调**——没有一家让用户从零设计。

**我们的先天优势**：标题是流水线上游 LLM 已生成的、底图是口播数字人视频（人物位置稳定），自动匹配的两个输入天然都有。因此封面自动生成应做成**合成步的默认行为**（零用户操作出默认封面），封面设计台只服务想精修的人——与对标产品「用户主动设置封面」正好反过来。

**自动生成管线（嵌入 compose 步）**

```
标题（上游 LLM 已生成）────────────┐
                                  ▼
视频 ─① 抽帧选底图 ─② 套模板填槽位 ─③ 可读性自适应 ─④ 多画幅导出
```

1. **底图自动获取**：P0 直接取开场 1s 处帧（口播视频人物位置固定，几乎必然合格）；P1 升级为每 2s 抽帧 8~12 张 → 清晰度（Laplacian 方差）+ 人脸状态打分 → 前 3 张做候选（对标 YouTube 三选一）。
2. **模板槽位自动填充**：核心是标题自动排版——**按字数分级**：≤8 字特大号单行、9~~14 字大号单行、15 字以上折两行降一级字号；关键词高亮由上游 LLM 生成标题时顺带用 `【】` 标注 1~~2 个爆点词，渲染时换色。
3. **可读性自适应**（自动化防翻车关键）：对标题落区做亮度采样 → 亮底图加深遮罩、暗底图减淡；文字始终带描边/投影，保证任意底图套任意模板对比度达标。
4. **多画幅导出**：RatioLayout 查表（§3.2），一次输出全平台画幅。
5. **P2 加分**：开源抠图（rembg / BiRefNet 本地跑）把人物抠出压在标题上方——必剪「智能抠图爆款封面」同款层次。

**分期**：P0 = 固定帧底图 + 预设模板 + 字数分级排版 + 遮罩自适应（Pillow 实现，无新增重依赖），合成时全自动出默认封面；P1 = 智能选帧 3 候选 + LLM 爆点词高亮 + 设计台微调；P2 = 人像抠图分层 + 模板库运营。

## 4. 字幕处理系统

### 4.1 配置维度（预设优先，参数兜底）

**样式预设（6 款样式卡，一键套用）**：经典白字描边、黄底黑字条、关键词高亮、卡拉OK逐字、圆角气泡条、双语上下行。

**高级参数（折叠二级）**

| 维度       | 选项                                                                      | 默认              |
| ---------- | ------------------------------------------------------------------------- | ----------------- |
| 字体       | 思源黑体 / 阿里巴巴普惠体 / 思源宋体 / 站酷高端黑（均可商用，随镜像打包） | 思源黑体 Bold     |
| 字号       | 32–72px（按 1080 宽基准）                                                 | 54                |
| 颜色       | 主色 + 关键词色（双色轮）                                                 | #FFFFFF + #FDE047 |
| 描边/阴影  | 0–6px 描边 + 投影开关                                                     | 3px 黑描边        |
| 背景条     | 无 / 半透明黑条 / 圆角色块                                                | 无                |
| 位置       | 顶部 / 中部 / 底部安全区（预览显示平台 UI 遮挡热区）                      | 底部安全区        |
| 关键词高亮 | AI 自动提取（划重点）+ 手动增删，套色或花字                               | AI 自动           |
| 动画       | 无 / 逐行淡入 / 卡拉OK逐字 / 弹跳强调                                     | 无                |

**底部安全区**：9:16 预览叠加抖音/快手 UI 遮挡热区（右侧操作栏、底部文案区约 300px），字幕位置滑动时给出"将被点赞按钮遮挡"警示——竞品普遍缺失、口播场景高频踩坑的点。

### 4.2 字幕校对 → 文本驱动剪辑（Descript 实践）

字幕区从只读升级为可编辑列表，每行 = ASR 词组块（后端已有 `subtitle_words` 词级时间戳）：

- **改字**：行内直接编辑，重合成时以修正文本渲染 ASS（时间戳不变）；
- **拆行/并行**：控制每屏字数（默认 ≤12 字，对齐 `_build_ass` 分组逻辑）；
- **删行即裁片（P2）**：删除一行 = 在 compose 时裁掉对应时间段（`ffmpeg trim+concat`），口播去口误零门槛；
- 点击任意行，预览播放头跳转至该行 `start`。

### 4.3 技术实现：参数化 `_build_ass()`

现状 `Style: Default,Arial,54,&H00FFFFFF,...` 写死。改造为由 `subtitle_style` 生成：

```python
def _build_ass(words, width, height, style: SubtitleStyle) -> str:
    # 1) Style 行：Fontname/Fontsize/PrimaryColour/OutlineColour/Outline/
    #    Alignment(2底/5中/8顶)/MarginV 全部来自 style
    # 2) BorderStyle=3 + BackColour 实现背景条
    # 3) 关键词高亮：命中词包裹 {\c&H47E0FD&}词{\c}   (BGR)
    # 4) 卡拉OK：逐词 {\k<厘秒>} 标签（词级时间戳现成）
    # 5) 逐行淡入：{\fad(120,0)}
```

- 颜色换算：`#RRGGBB` → ASS `&HBBGGRR&`；字号按 `PlayResX=1080` 基准等比。
- 字体随镜像打包至 `/app/fonts`，compose 命令追加 `:fontsdir=/app/fonts`。
- BGM 同步修复：`volume=0.12` → `volume={bgm_volume/100}`，并以 `sidechaincompress`（人声侧链压 BGM）实现真实闪避，替代当前文案宣称的"自动闪避"。
- 前端预览与服务端渲染共用同一份 `SubtitleStyle` schema（`client/packages/types`），CSS 模拟预览、ASS 定稿，误差控制在字体渲染层面。

## 5. 剪辑界面 V2 设计

### 5.1 布局：三区工作台（效果图 `editor-v2.html`）

```
┌────────────────────────────────────────────────────────┐
│ 顶栏：任务选择 · 画幅切换(9:16/16:9/1:1) · 保存并重新合成 │
├───────────────┬────────────────────────────────────────┤
│               │  Tab: 字幕 | 封面 | 音乐 | 片段          │
│  预览舞台      │  ── 字幕：6 样式卡 + 高级参数折叠         │
│  (随画幅切换)  │  ── 封面：模板 + 多平台画幅条 → 进封面台   │
│  安全区叠加    │  ── 音乐：三模式 + 人声/BGM 双轨音量      │
│  字幕实时预览  │  ── 片段：分割/排序/删除（P2 文稿剪辑）   │
├───────────────┴────────────────────────────────────────┤
│ 时间线：视频轨 · 字幕轨(逐行块,当前行高亮) · BGM 轨       │
├────────────────────────────────────────────────────────┤
│ 字幕校对（可编辑 · 点击行跳播放头 · 关键词标记）           │
└────────────────────────────────────────────────────────┘
```

设计要点：

- **单一视觉焦点**：预览舞台始终第一焦点；右侧面板 Tab 化收纳四类配置，替代 V1 的纵向卡片长滚动；
- **预设卡片直接展示效果**（样式卡内渲染真实字幕效果字样，不是文字描述）；
- 保留现有页面骨架（侧栏/顶栏/动线条），沿用 `assets/style.css` 设计系统，不引入新的视觉语言。

### 5.2 用户交互流程

```
任务中心/合成完成 → 进入剪辑台(自动带 task 参数)
  → 预览成片 → 切 Tab 调字幕样式(实时预览) → 校对区改错字
  → 切封面 Tab → 选模板/改标题 → (可选)进封面设计台精修多平台封面
  → 音乐 Tab 调双轨音量 → 「保存并重新合成」
  → 原地进度条(WS+轮询,复用第5步合成面板模式) → 新成片就绪
  → 「去发布」(封面按平台自动带对应画幅)
```

状态设计：无候选任务空态（引导去创建）/ 重合成中(禁用保存、进度环) / 合成失败（错误条 + 一键重试）/ 有未保存修改（顶栏 dirty 标记 + 离开拦截）。

### 5.3 封面设计台（效果图 `cover-designer.html`）

从剪辑台封面 Tab「精修」进入的二级页面：

- 顶部平台画幅条：抖音 9:16 / 小红书 3:4 / 小红书横 4:3 / 视频号 6:7 / B站 16:9，切换即重排；
- 中央画布：所选画幅 + 安全区参考线（抖音 3:4 裁切框）+ 分层渲染；
- 右侧图层面板：底图（取帧滑杆）/ 遮罩 / 标题（AI 3 候选）/ 角标 / 贴片；
- 底部「全平台导出预览」条：同一 spec 在 5 个画幅的缩略图横排，直观验证横竖屏差异化效果。

## 6. 落地路线

| 阶段                 | 内容                                                                                                                   | 验收标准                                                                                 |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **P0（打通真链路）** | `_build_ass` 参数化消费 `subtitle_style`；`bgm_volume` 落地 + sidechain 闪避；字体打包                                 | 前端改字号/颜色/位置后重合成，成片肉眼可见变化；BGM 音量随滑杆变化                       |
