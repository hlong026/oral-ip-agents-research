## 2. 项目概述

### 2.1 产品定位

面向个人 IP 创作者、电商卖家与矩阵运营团队的「口播视频全链路智能体」——输入一个爆款链接或一个选题，自动完成文案、声音、数字人、剪辑、发布与数据回流，让一个人跑通一支内容团队。

标准流水线：

```
对标链接/选题 → 文案提取(ASR) → 文案仿写(LLM) → 去重度检测 → 声音克隆(TTS)
→ 数字人口播(形象克隆/唇形驱动) → 字幕/BGM/标题/封面(FFmpeg) → 多平台发布
```

### 2.2 目标用户

| 用户类型                             | 核心场景                           | 付费特征                   |
| ------------------------------------ | ---------------------------------- | -------------------------- |
| 个人 IP 创作者（口播/知识/电商博主） | 不出镜日更、爆款复刻               | 买断敏感，¥799–1999 价格带 |
| 电商卖家 / 本地生活商家              | 带货视频、获客视频批量产出         | 按效果付费意愿强           |
| MCN / 矩阵工作室                     | 多账号批量生产、定时分发、数据回流 | 付费意愿最强，矩阵刚需     |

### 2.3 差异化主张（按裁决 C1/C14 修订）

| 竞品短板                   | 我们的对策                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| 旗博士吃显卡、隐性租机消费 | **云端为主、本地备用**：默认全任务走云端 GPU 池，低配机零门槛；高配用户 V1.5+ 可接入本地引擎免额度 |
| 罗根纯云端、续费贵         | 云算力按量透明计费、消耗明细可导出；本地免额度通道（V1.5+）作为重度用户降本出口                    |
| 仅轻语覆盖全终端           | Web 主端 + Win/Mac 客户端 + iOS/Android 五端协同（MVP 为 Web + 桌面壳，移动端 V1.1 补齐）          |
| 同质化内容被限流           | 人设引擎 + 文案去重度检测 + 差异化参数随机化 + 平台合规预检                                        |
| 发布接口易失效             | 发布通道适配层 + 失效自动告警 + 半自动导出兜底                                                     |
| 工具无沉淀                 | IP 资产库（人设/声音/形象/素材/模板）持续增值                                                      |

### 2.4 商业模式

- **买断授权 + 云算力按量计费**（额度点数制，透明可查可导出）；
- 本地引擎（V1.5+）作为买断用户的高配权益，免扣云端额度；
- 课程/陪跑、模板中心、企业定制（V2.0+ 私有化/API）为第二增长曲线；
- 合规红线：倒包（逆向第三方 App 接口）类灰色方案一律不进入商业产品。

### 5.2 端到端 5 分钟预算分解（G4）

| 步骤              | 预算                                        | 依据                                                           |
| ----------------- | ------------------------------------------- | -------------------------------------------------------------- |
| ① 链接解析        | ≤10s                                        | 03 §1.2（重定向 + 下载）                                       |
| ② ASR 转写        | ≤30s                                        | 云端 API 上限（本地 GPU ≤10s）                                 |
| ③ 文案仿写 + 去重 | ≤15s                                        | LLM 生成 ≤10s + Embedding 检测                                 |
| ④ TTS 合成        | ≤30s                                        | MiniMax 1 分钟音频 ≤30s                                        |
| ⑤ 数字人渲染      | **≤3.5min（P95，准入门槛，待 Spike 验证）** | 飞影 API 实测耗时尚无数据，**不填推测值**；W3 前完成实测并回写 |
| ⑥ 合成（FFmpeg）  | ≤30s                                        | 60s 1080P 本地/云端合成                                        |
| ⑦ 发布            | 不计入成片预算                              | 异步执行，单独 SLO                                             |
| **合计（成片）**  | **≤5min（P50）**                            | 排队时长单独计量，不计入处理耗时                               |

### 5.3 并发模型

| 层级       | 承诺                      | 供应商/资源映射                                                            |
| ---------- | ------------------------- | -------------------------------------------------------------------------- |
| 任务级并发 | ≥5 任务并行，批量队列 ≥20 | 并发闸门在 pipeline.batch 控制                                             |
| TTS        | 5 任务 × 1 次合成         | MiniMax 套餐 RPM 60–500，远低于上限 ✅                                     |
| 数字人     | 5 任务同时渲染            | 飞影单黑金账号并发有限 → **需实测并发上限，必要时 N 账号池化**（待 Spike） |
| ASR/合成   | 云端 Worker 槽位          | 4090 单卡槽位数 = f(单任务显存)，容量公式见 11.3                           |

### 5.4 可用性预算与降级矩阵（≥99.5%）

| 组件                       | 可用性目标             | 降级链（主 → 备 → 人工）                                       |
| -------------------------- | ---------------------- | -------------------------------------------------------------- |

| 任务队列（Redis/Dramatiq） | 99.9%                  | 持久化 + 重试                                                  |

## 7. 算力架构与调度（ComputeRouter）

### 7.1 路由策略

```
默认策略 CLOUD_FIRST:
  任务到达 → 云端 GPU Worker 池(默认通道, 按步骤扣额度)
  ├─ 用户已接入本地引擎(V1.5+, 可选): Agent 心跳在线且 capabilities 覆盖该步骤
  │    → 路由本地(免扣额度); 产物直传 S3, 进度回传
  ├─ 本地未接入/离线/步骤不支持 → 自动回落云端, 用户无感知
  └─ 批量任务: 每步独立路由 → 异构混跑(本地跑 ASR+合成, 云端跑数字人)
```

- 路由优先级：`用户显式选择 > 本地 Agent 可用性 > 云端默认`；云端是永远生效的兜底通道。
- MVP 阶段仅云端通道生效；本地路由代码与心跳协议随 Worker 一并实现但默认关闭。

### 7.2 步骤 × 通道能力矩阵

| 步骤      | 云端 API              | 云端自建 Worker             | 本地 Agent（V1.5+） |
| --------- | --------------------- | --------------------------- | ------------------- |
| 解析      | ✅（第三方 API 兜底） | ✅（自建解析）              | ✅                  |
| ASR       | ✅                    | ✅ faster-whisper           | ✅（8G 显存可用）   |
| 仿写/去重 | ✅ LLM/Embedding API  | —（API 调用）               | —（API 调用）       |
| TTS       | ✅ MiniMax            | ✅ CosyVoice2（V1.1+ 降本） | ✅（有显卡时）      |
| 数字人    | ✅ 飞影               | ✅ HeyGem（V1.5+）          | ⚠️ 高配可选         |
| 合成      | ✅（IMS 兜底，少用）  | ✅ FFmpeg                   | ✅ FFmpeg           |
| 发布      | ✅（控制面执行）      | —                           | ❌（统一走控制面）  |

### 7.3 心跳协议与排队水位

- 心跳（本地引擎接入后启用）：`{agent_id, gpu:{model,vram_mb,free_mb}, caps:["asr","tts","compose"], load:0-1, version}`，30s 周期，90s 无心跳判离线自动切云。
- 排队水位：**云端排队 >10 任务或预计等待 >5 分钟**时触发：① 向前端推送"接入本地引擎加速"引导；② GPU 池自动扩容（触发水位见 11.3）。

## 8. 模块设计

每节固定结构：职责 → 选型与降级链 → 性能指标 → 单条成本 → 验收标准（对应 F 编号）。

### 8.1 文案模块（content）

- **职责**：链接解析编排 → ASR 编排 → LLM 仿写/改写/选题 → 去重度检测 → 标题/话题生成。
- **选型与降级链**：
  - ParseProvider：自建解析微服务（抖音/快手/小红书）→ 第三方解析 API → 手动上传/粘贴降级；
  - ASRProvider：faster-whisper（本地/自建 GPU）→ FunASR → 云端 ASR API（火山/阿里，~¥1.5–3/小时）；
  - LLMProvider：DeepSeek-V3（主力）→ 豆包（成本敏感）→ 云雾中转（容灾降本）；Embedding：BGE-M3 + n-gram 双指标。
- **性能**：解析 ≤10s；ASR ≤10s(本地)/≤30s(云端)；仿写 ≤10s；去重 ≤2s。
- **单条成本**：LLM ¥0.01–0.02 + Embedding ≈¥0.001 + ASR（本地 0 / 云端 ≈¥0.05）。
- **验收**：F-101~F-106（修订后标准见 4.1）。

### 8.2 声音模块（voice）

- **职责**：声音克隆、TTS 合成、音色库、情绪语气；克隆授权校验。
- **选型与降级链（三层声音架构）**：
  1. **默认主力：MiniMax Speech-02 API**（快速克隆生成 voice_id，HD ≈¥0.32/千字符，Turbo ≈¥0.18/千字符）；
  2. **降本层（V1.1+）：开源自部署 CosyVoice2 / GPT-SoVITS**（用户本地有显卡或云端 4090 批量任务免费额度化）；
  3. **禁用层：倒包逆向方案不进入产品**（合规红线，仅内部预研评估）。
- **接口**：`VoiceProvider` Protocol（clone / synthesize / list_voices），synthesize 返回字级时间戳供字幕双模式。
- **性能**：克隆 ≤10min；合成 1 分钟音频 ≤30s。
- **单条成本**：60s 口播 600–800 字 ≈ **¥0.2–0.3（HD）**。
- **验收**：F-201~F-204。

### 8.3 数字人模块（avatar）

- **职责**：形象克隆（视频/照片）、公共形象库、口型驱动渲染、多形象管理；克隆授权校验。
- **选型与降级链（双轨）**：
  - **MVP：飞影 API（黑金版 ¥349/月，视频生成不耗积分 = 固定成本不限量通道）**，官方账号统一调度 + 内部任务队列 + 公平配额；接口覆盖形象克隆（视频/照片）、公共库、声音克隆（互补）、音频/TTS 驱动、内置字幕参数；
  - **V1.5+：HeyGem / Duix-Avatar 私有化集群**（量大后边际成本趋零，作"本地算力"卖点）；
  - 长期：`AvatarProvider` 抽象层同时挂载飞影/HeyGem/大厂 API，按任务类型智能路由；
  - **云雾 API 不适用本模块**（无形象克隆/唇形驱动接口），仅用于文案模块 LLM 降本。
- **性能**：60s 视频渲染 **P95 ≤3.5min（准入门槛，待 Spike 实测，不填推测值）**；并发上限待实测，必要时多账号池化。
- **单条成本**：黑金版摊销 ≈¥0（封顶 ¥349/月/账号）；HeyGem 私有化 ≈¥0.1–0.3；HeyGen ≈¥7–20（仅出海备选）。
- **验收**：F-301~F-304。

### 8.4 视频合成模块（compose）

- **职责**：字幕烧录、画中画/多镜头、BGM 混音闪避、封面、多比例输出、批量队列、差异化随机化。
- **选型（路线 B + D）**：
  - **主路线：FFmpeg 子进程 + Python 编排层**，架构借鉴 MoneyPrinterTurbo（MIT）——concat / overlay / subtitles(ASS) / sidechaincompress / scale+pad；GPU 可选 h264_nvenc 加速 5–10 倍；低配云端兜底；
  - **增值导出（P1，F-407）**：pyJianYingDraft 生成剪映草稿，导出失败降级 MP4 直出；
  - **排除**：Remotion（>3 人营利需付费授权）；商业云剪辑 API 仅作云端兜底（阿里 IMS 1080P ¥0.06/分钟）。
- **性能**：60s 1080P 合成 ≤30s。
- **单条成本**：本地/自建 ≈¥0–0.02；IMS ≈¥0.06。**合成不是成本中心，效果与差异化才是竞争力。**
- **验收**：F-401~F-407。

### 8.5 发布模块（publish）

- **职责**：发布适配层、账号登录态管理、发布任务/记录、失效告警。
- **选型方向（G1，待 W3 预研确认）**：social-auto-upload 二开为主 + RPA 兜底；登录态 Cookie 加密存 PG、会话态存 Redis；扫码授权。
- **关键风险**：平台风控升级导致上传失效（01 报告用户痛点 #4）→ 发布适配层快速迭代 + 半自动导出兜底 + 多通道冗余。
- **性能/SLO**：发布异步执行；失败自动重试 + 告警（通知模块）；成功率目标 ≥90%（待验证）。
- **验收**：F-501~F-504。

### 8.6 计费模块（billing）

- **职责**：License 签发（Ed25519 离线可验）、额度计量扣费、明细导出、价格表管理。
- **设计**：额度价格表存 PG（`quota_price: step × resolution × unit_price`）；流水线每步完成产生计量事件（关联 trace_id）→ 扣减额度；扣费事务语义见 11.2。
- **验收**：F-601/F-602。

### 8.7 通知模块（notify）

- **职责**：WebSocket 事件网关 + 多通道通知（App 推送/微信模板消息/邮件）。
- **设计**：Worker 进度事件经 Redis Pub/Sub → WS 网关 → 各端；Provider 降级事件、发布失败、额度不足均在此汇聚告警（对齐非功能需求"降级可见"）。
- **验收**：F-734（P1）。

## 10. 后端设计

### 10.1 模块六件套约定

每个业务模块 = `router.py`（HTTP 层，仅参数校验与调用 service）/ `service.py`（业务编排）/ `models.py`（ORM）/ `schemas.py`（Pydantic 出入参）/ `repository.py`（数据访问）/ `events.py`（领域事件，发 Redis Pub/Sub 供 notify/billing 消费）。

**护栏**：模块间只允许通过 service 公开函数 + 领域事件通信，禁止跨模块 import models——这是单体向微服务平滑演进的边界。模块清单：auth / billing / ipasset / content / pipeline(★核心) / publish / analytics(P1) / notify。

### 10.2 流水线引擎（pipeline）

```python
STEP_ORDER = ["parse", "asr", "rewrite", "voice", "avatar", "compose", "edit", "publish"]
# UI 7 步映射: 链接/选题(parse+asr) → 文案(rewrite) → 声音(voice) → 数字人(avatar)
#              → 合成(compose) → 剪辑(edit, 自动模式可跳过) → 发布(publish)
# 状态机: PENDING → RUNNING(step1..8) → DONE / FAILED
# 每步: emit(running) → ComputeRouter.pick(step) → step.run(ctx)
#       → 失败时按降级链换 Provider 重试 → artifacts 落库 → emit(done, 计量事件)
# mode=manual 时每步完成暂停等待用户确认（F-405 单步干预）
# 支持单步重跑 /retry；文案与剪辑修改走版本化接口；批量任务扇出 + 并发闸门(≥5)
```

- 每步产出物写入 `ctx.artifacts` 持久化，任务可断点续跑；
- 每步 `done` 事件携带计量信息 → billing 扣减额度（trace_id 贯穿）；
- 步骤级超时 + 任务级看门狗；`StepRecoverableError` 触发降级链并记录事件（任务中心可见）。

### 10.3 Provider 抽象层

七类 Protocol：`LLMProvider`（rewrite/generate_topics/check_similarity）、`ParseProvider`、`ASRProvider`、`VoiceProvider`（clone/synthesize→字级时间戳/list）、`AvatarProvider`（clone_by_video/create_by_audio/query_task/list_public）、`ComposeEngine`、`PublishDriver`。

- `clone()` 均强制传入 `consent_token`（本人授权凭证，合规红线）；
- `registry.py` 按「用户配置 → 租户默认 → 系统默认」三级解析实现（如 `voice.primary=minimax, voice.fallback=cosyvoice_local`），主实现异常自动降级并记事件；
- 新增供应商 = 新建文件实现 Protocol + 注册一行，零改动业务代码。

### 10.6 日志体系设计

> **背景**：代码审查发现 auth/billing/pipeline 服务层、Provider 降级链、LLM 调用等关键路径日志严重缺失，生产环境无法追踪用户使用记录、扣费流水及业务异常。本节定义全链路日志规范，确保从用户操作到后台处理的完整可追溯性。

#### 10.6.1 基础设施

**技术选型**：`structlog`（结构化日志）+ `contextvars.ContextVar`（请求级上下文注入）

```python
# server/app/core/logging.py（新建）
import logging, structlog
from contextvars import ContextVar

trace_id_var: ContextVar[str] = ContextVar("trace_id", default="")
user_id_var:  ContextVar[str] = ContextVar("user_id",  default="")
task_id_var:  ContextVar[str] = ContextVar("task_id",  default="")

def setup_logging(app_env: str = "dev") -> None:
    structlog.configure(
        processors=[
            structlog.contextvars.merge_contextvars,
            _inject_context,          # 自动注入 trace_id / user_id / task_id
            structlog.processors.add_log_level,
            structlog.processors.TimeStamper(fmt="iso"),
            structlog.processors.StackInfoRenderer(),
            structlog.processors.format_exc_info,
            _sanitize,                # 敏感字段脱敏（见 10.6.4）
            structlog.dev.ConsoleRenderer()              if app_env == "dev"
            else structlog.processors.JSONRenderer(ensure_ascii=False),
        ],
        wrapper_class=structlog.make_filtering_bound_logger(logging.INFO),
    )
```

```python
# server/app/core/middleware.py（新建）
class TraceMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        tid = request.headers.get("X-Trace-Id") or uuid.uuid4().hex[:16]
        trace_id_var.set(tid)
        response = await call_next(request)
        response.headers["X-Trace-Id"] = tid
        return response
```

#### 10.6.3 全链路 trace_id 贯通规范

```

       ↓
WS 事件 payload 携带 traceId（已实现，engine.py _emit）
       ↓

```

## 11. 成本模型

> 以下均为 **2026-07 价格锚点**，供应商价格变动频繁，实施前必须复核（G5）。

### 11.1 单条视频端到端成本汇总（60s 1080P）

| 步骤      | 默认云端路径               | 本地免费路径（V1.5+，高配用户） | 全 API 兜底路径                 |
| --------- | -------------------------- | ------------------------------- | ------------------------------- |
| 解析      | ≈0（自建）                 | ≈0                              | ≈0.01（第三方 API 摊销）        |
| ASR       | ≈0（自建 Worker）          | 0（本地 faster-whisper）        | ≈¥0.05（云 API）                |
| 仿写+去重 | ¥0.01–0.02                 | 同左（API 调用）                | ¥0.01–0.02                      |
| TTS       | ¥0.2–0.3（MiniMax HD）     | 0（本地 CosyVoice2）            | ¥0.2–0.3                        |
| 数字人    | ≈0（飞影黑金封顶 ¥349/月） | 0（本地 HeyGem，高配）          | HeyGen ≈¥7–20（仅出海）         |
| 合成      | ≈¥0.02（自建摊销）         | 0（本地 FFmpeg）                | ≈¥0.06（IMS）                   |
| **合计**  | **≈¥0.25–0.35/条**         | **≈¥0.01–0.02/条**              | **≈¥0.3–0.5/条（不含 HeyGen）** |

重度矩阵用户（日更 100 条）月度参考：TTS 一项约 ¥800–1500（MiniMax 按量），是主要变动成本 → 推动其迁移开源自部署或本地通道是降本核心。

### 11.2 额度定价模型与扣费事务

- `quota_price` 表：`step × resolution × unit_price`，点数↔人民币汇率由运营定价（建议毛利率 ≥60%，按 11.1 默认路径成本核算）；
- 扣费语义：**步骤成功后扣费、失败自动退还**（对齐云厂商"失败不扣费"惯例）；计量事件关联 trace_id，明细可导出 CSV（F-602）；
- 本地通道执行的步骤**免扣额度**并在任务卡标注（"本地节点"徽标）。

### 11.3 GPU 容量公式与扩容水位

- 自建 Worker 容量：`卡数 = 目标并发 × 单条耗时 ÷ 单卡吞吐(条/小时)`；单卡吞吐基准（HeyGem/CosyVoice/faster-whisper on 4090）**待 Spike 实测，不填推测值**；
- 扩容水位：队列深度 > 卡数 × 3 或预计等待 >5 分钟时自动扩容 4090 弹性实例；
- MVP 起步：4090 ×1–2（ASR/合成自建），数字人走飞影 API 不占自建 GPU。

### 11.4 供应商切换拐点与存储容量

- 飞影 → OEM/商务谈判拐点：**月生成 >1 万分钟**；飞影 → HeyGem 私有化拐点：月 GPU 成本 < API 月费且团队具备运维能力；
- 存储：60s 1080P 成片约 20–50MB；日 1000 条 ≈ 20–50GB/天新增 → MinIO 起步，热数据 30 天、冷数据归档 OSS 生命周期策略；素材/成片均走预签名 URL 直传。

## 12. 合规与风控

### 12.1 合规红线

1. **倒包类灰色方案一律不进入商业产品**：逆向第三方 App（剪映等）接口违反平台协议，涉嫌《反不正当竞争法》第 12 条及《刑法》第 285 条，仅允许内部技术预研评估；
2. **声音/形象克隆强制授权**：上传样本前活体/授权校验，接口层强制 `consent_token`；产物水印溯源；
3. **批量抓取合规**：用户协议声明"仅限已授权内容使用"，不提供无差别爬取能力；
4. **AI 内容标识**：按各平台规则自动添加/适配（F-712，审核 API 选型待补，G2）。
