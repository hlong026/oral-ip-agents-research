# 16 - 生产切换上线检查清单

> 配套：`server/.env.production.example`（配置基线）。目标：机制性保证生产环境零 Mock 产物，
> 任何降级到演示数据的结果要么被拒收，要么带全链路"演示数据"标记。

## 机制性防线（代码层已内置，无需人工干预）

| 防线 | 位置 | 行为 |
| --- | --- | --- |
| 零 Mock 启动自检 | `app/providers/registry.py` | `APP_ENV=prod` 时任何链混入 `mock-` provider 立即抛异常拒绝启动 |
| Mock 开关按环境推导 | `app/core/config.py` | 非 dev/test 环境 `mock_fallback_allowed` 无条件 False，不受 .env 误配影响 |
| Pipeline 拒收防线 | `app/modules/pipeline/engine.py` | parse/asr/voice/avatar/compose 步收到 Mock 结果：prod 转任务失败；dev/test 打 `degraded_mock` 标记 |
| Content 拒收防线 | `app/modules/content/service.py` | 链接解析/转写降级到 Mock 时拒绝落库占位文案 |
| 安全密钥强校验 | `app/core/config.py::validate_runtime_security` | 生产缺少任一密钥拒绝启动；`IM_ENABLED=true` 拒绝启动 |
| CI 门禁 | `server/tests/test_production_no_mock.py` | prod 注册表零 Mock、pipeline 拒收 Mock 回归单测 |

## 上线四步检查

### 第 1 步：环境变量

- [ ] 复制 `server/.env.production.example` 为 `.env`，确认 `APP_ENV=prod`
- [ ] 五把密钥全部替换为互不相同的高强度随机值：`APP_SECRET` / `CONFIG_ENCRYPTION_KEY` / `ACTIVATION_SECRET` / `PUBLISH_SESSION_ENCRYPTION_KEY` / `FEIYING_WEBHOOK_SECRET`
- [ ] `DATABASE_URL` 指向生产 PostgreSQL、`REDIS_URL` 指向生产 Redis
- [ ] `MEDIA_PUBLIC_BASE_URL` 公网可达（云端 ASR 回源下载依赖）
- [ ] `CORS_ORIGINS` 填写正式前端域名
- [ ] `IM_ENABLED=false`（合规 No-Go，开启会拒绝启动）
- [ ] 前端构建时不设置 `VITE_ANALYTICS_PREVIEW` / `VITE_ASSETS_PREVIEW`（V1.1 占位页保持隐藏）
