# 口播IP智能体 · 产品功能需求清单（PRD-Feature List）

- 版本：v1.0（基于 [01-市场调研报告](01-市场调研报告.md) 输出）
- 日期：2026 年 7 月
- 状态：待评审

---

## 1. 产品定位

**一句话**：面向个人 IP 创作者、电商卖家与矩阵运营团队的「口播视频全链路智能体」——输入一个爆款链接或一个选题，自动完成文案、声音、数字人、剪辑、发布与数据回流，让一个人跑通一支内容团队。

**差异化主张**（针对竞品短板设计）：

| 竞品短板                   | 我们的对策                                     |
| -------------------------- | ---------------------------------------------- |
| 旗博士吃显卡、隐性租机消费 | 混合算力智能调度：本地优先、云端兜底、按量透明 |
| 罗根纯云端、续费贵         | 本地永久免费 + 云端订阅可选                    |
| 仅轻语覆盖全终端           | Win/Mac 客户端 + iOS/Android + Web 五端协同    |
| 同质化内容被限流           | 人设引擎 + 文案去重度检测 + 平台合规预检       |
| 发布接口易失效             | 发布通道适配层 + 失效自动告警 + 半自动兜底     |
| 工具无沉淀                 | IP 资产库（人设/声音/形象/知识库）持续增值     |

---

## 2. 功能总览（MoSCoW 分级）

- **P0 核心功能**（Must）：没有就不是口播IP智能体，MVP 必备
- **P1 辅助功能**（Should）：显著提升体验与竞争力，V1.1–V1.5 补齐
- **P2 扩展功能**（Could）：构筑壁垒与第二增长曲线，V2.0+ 规划

## 3. P0 核心功能

### 3.1 爆款对标与文案模块

| 编号  | 功能            | 需求描述                                                      | 验收标准                                             |
| ----- | --------------- | ------------------------------------------------------------- | ---------------------------------------------------- |
| F-101 | 链接解析提取    | 粘贴抖音/视频号/小红书/快手分享链接，自动去水印下载并提取视频 | 支持 4 平台；解析成功率 ≥95%                         |
| F-102 | 语音转写（ASR） | 对提取视频进行语音识别，输出带时间轴文案                      | 中文转写准确率 ≥95%（Whisper large-v3 / Paraformer） |
| F-103 | 爆款文案仿写    | 基于 LLM 对文案做语义级仿写与结构重组，保留爆款结构、替换表达 | 生成 ≤10s；支持 3 种仿写强度                         |
| F-104 | 自定义指令改写  | 用户输入 Prompt 指定风格/行业/口吻/时长                       | 支持指令模板保存复用                                 |
| F-105 | 选题生成        | 无对标链接时，输入关键词自动生成候选选题与文案                | 单次产出 ≥5 个选题                                   |
| F-106 | 文案去重度检测  | 输出与原文相似度评分，提示搬运风险                            | 给出 0–100 相似度分与改写建议                        |

### 3.2 声音模块

| 编号  | 功能       | 需求描述                                          | 验收标准                               |
| ----- | ---------- | ------------------------------------------------- | -------------------------------------- |
| F-201 | 声音克隆   | 上传/录制 3–5 分钟音频即可克隆音色                | 相似度主观评测 ≥4/5；克隆耗时 ≤10 分钟 |
| F-202 | TTS 合成   | 文案转语音，支持语速（0.8–1.2）、停顿、多音字纠偏 | 合成 1 分钟音频 ≤30s                   |
| F-203 | 音色库     | 内置 ≥20 个商用授权音色；支持用户多音色管理       | 音色可增删改、绑定到 IP                |
| F-204 | 情绪与语气 | 按文案情绪自动匹配语气（可选）                    | 至少 5 种情绪风格                      |

### 3.3 数字人模块

| 编号  | 功能         | 需求描述                                    | 验收标准                        |
| ----- | ------------ | ------------------------------------------- | ------------------------------- |
| F-301 | 形象克隆     | 上传 30s–2min 真人出镜视频，训练专属数字人  | 1080P 输出；唇形同步误差 ≤100ms |
| F-302 | 免训练形象库 | 内置 ≥50 个通用数字人形象，即选即用         | 含男女/年龄/职业风格覆盖        |
| F-303 | 口型驱动     | 音频驱动数字人口播（Wav2Lip/HeyGem 类方案） | 口型自然度主观 ≥4/5             |
| F-304 | 多形象管理   | 一个账号管理多个数字人，绑定不同 IP/场景    | 形象独立存储、随时切换          |

### 3.4 视频合成模块

| 编号  | 功能       | 需求描述                                             | 验收标准                  |
| ----- | ---------- | ---------------------------------------------------- | ------------------------- |
| F-401 | 自动字幕   | 按时间轴生成字幕，支持字号/颜色/位置/描边            | 字幕与音频误差 ≤200ms     |
| F-402 | 背景音乐   | 自动匹配 BGM / 自定义上传 / 关闭三模式；自动闪避人声 | BGM 音量自适应            |
| F-403 | 标题与话题 | 自动生成发布标题 + 话题标签（平台风格适配）          | 每平台生成 ≥3 组候选      |
| F-404 | 封面生成   | 自动抽帧/模板生成封面，支持自定义编辑                | 适配各平台尺寸规范        |
| F-405 | 一键成片   | 从链接/选题到成片的流水线全自动执行，单步可干预      | 全流程 ≤5 分钟/条         |
| F-406 | 批量生成   | 一次提交多条任务，队列化生产                         | 支持 ≥20 条队列，失败重试 |

### 3.5 发布模块

| 编号  | 功能       | 需求描述                                | 验收标准                     |
| ----- | ---------- | --------------------------------------- | ---------------------------- |
| F-501 | 多平台发布 | 抖音、视频号、小红书、快手一键/定时发布 | 覆盖 4 平台；发布成功率 ≥90% |
| F-502 | 账号管理   | 多平台账号授权/登录态管理，登录失效提醒 | 支持 ≥10 账号                |
| F-503 | 发布配置   | 各平台标题/封面/话题/定时时间独立配置   | 单条视频可差异化配置         |
| F-504 | 发布记录   | 发布状态追踪与失败原因反馈              | 全量日志可查                 |

### 3.6 账号与计费

| 编号  | 功能       | 需求描述                                | 验收标准           |
| ----- | ---------- | --------------------------------------- | ------------------ |
| F-601 | 用户体系   | 注册登录（手机/微信）、设备绑定         | 支持 5 端登录同步  |
| F-602 | 授权与额度 | 买断授权 + 云算力额度管理，用量透明可查 | 额度消耗明细可导出 |

## 4. P1 辅助功能

## 6. 非功能需求

| 类别     | 要求                                                                 |
| -------- | -------------------------------------------------------------------- |
| 性能     | 单条视频端到端 ≤5 分钟；批量队列并发 ≥5；App 冷启动 ≤3s              |
| 算力架构 | 本地（Whisper/CosyVoice/HeyGem 类）+ 云端 GPU 弹性调度；任务智能路由 |
| 兼容性   | Windows 10+ / macOS 11+ / iOS 14+ / Android 10+ / 主流浏览器         |
| 安全     | 素材与形象数据加密存储；声音/形象克隆需本人授权校验（防滥用）        |
| 合规     | 内容审核接口；AI 生成标识；用户协议明确平台规则风险                  |
| 稳定性   | 发布通道失效自动降级（转半自动导出）；核心服务可用性 ≥99.5%          |
| 可维护   | 模块解耦（文案/音频/形象/合成/发布独立可替换），对齐主流工程实践     |

## 7. 版本规划建议

| 版本        | 范围                       | 目标                                       |
| ----------- | -------------------------- | ------------------------------------------ |
| MVP（V1.0） | F-101~F-601 全部 P0        | 跑通"链接 → 成片 → 发布"闭环，验证付费     |

## 8. 风险与对策

| 风险                     | 等级 | 对策                                                                |
| ------------------------ | ---- | ------------------------------------------------------------------- |
| 平台自动发布接口风控升级 | 高   | 发布适配层快速迭代；导出+半自动兜底；多通道冗余                     |
| 数字人内容被限流         | 高   | 去重检测、合规预检、真人素材混合策略引导                            |
| 开源组件许可证风险       | 中   | 替换/自研关键组件；法务审查（Whisper MIT、CosyVoice Apache-2.0 等） |
| 声音/形象侵权滥用        | 高   | 克隆前活体/授权校验，水印溯源                                       |
| 盗版分发                 | 中   | 云端算力绑定账号、持续更新、服务与课程差异化                        |
