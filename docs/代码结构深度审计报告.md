## 🔍 核心问题诊断

### 🔴 严重问题：文件超长（超过 1000 行）

#### 1. **CreatePage.tsx** (1629 行)
**问题描述**: 七步向导流程全部塞在一个组件中
- Step1-Step7 状态集中管理
- 价格预览、计量操作、UI 渲染混合
- 难以测试和维护

**风险等级**: ⚠️⚠️⚠️ 高（违反单一职责原则）

**推荐拆分方案**:
```typescript
// CreatePage.tsx (精简到 300 行)
- 主流程控制器（Wizard 状态管理）
- 步骤导航器（动态渲染子组件）

// 拆分后的子组件
/components/create-wizard/LinkStep.tsx (200 行)
/components/create-wizard/RewriteStep.tsx (250 行)
/components/create-wizard/VoiceStep.tsx (150 行)
/components/create-wizard/AvatarStep.tsx (180 行)
/components/create-wizard/ComposeStep.tsx (120 行)
/components/create-wizard/EditStep.tsx (200 行)
/components/create-wizard/PublishStep.tsx (200 行)
```

**预期收益**: 
- 每个子组件 < 250 行
- 并行开发不冲突
- 单元测试覆盖率提升至 80%+

#### 2. **EditorPage.tsx** (1079 行)
**问题描述**: 视频剪辑编辑器全功能堆叠
- FFmpeg 配置
- 字幕编辑
- 封面选择
- 多轨道混剪

**推荐拆分**:
```typescript
// EditorPage.tsx (200 行) - 页面外壳
- TimelineView.tsx (300 行) - 时间线视图
- SubtitleEditor.tsx (250 行) - 字幕编辑器
- VideoPreview.tsx (180 行) - 预览窗口
- ExportPanel.tsx (150 行) - 导出面板
```

#### 3. **pipeline/service.py** (1537 行)
**问题描述**: 管道编排引擎过度集中
- 步骤调度

**推荐拆分**:

## ✅ 架构优点

### 1. 前后端分离清晰
```
Frontend Layer:
- apps/web/ (CRA 用户端)
- apps/admin/ (管理后台)
- apps/desktop/ (Tauri 桌面壳)

Backend Layer:
- server/app/modules/ (按业务域垂直切分)
- server/app/core/ (横切关注点)

Shared Layer:
- packages/api-client/ (统一 HTTP/WebSocket 客户端)
- packages/types/ (TypeScript 类型定义)
- packages/hooks/ (复用 React Hooks)
```

### 2. 模块化单体后端设计优秀
- 每个业务模块自包含 `models.py`, `schemas.py`, `router.py`, `service.py`
- 依赖注入清晰 (`deps.py`)
- 迁移脚本按版本顺序组织 (`alembic/versions/`)

### 3. Monorepo 构建高效
```json
{
  "packageManager": "pnpm@9.15.0",
  "monorepoTool": "turbo",
  "sharedPackages": [
    "@oral/api-client",
    "@oral/types",
    "@oral/stores",
    "@oral/hooks"
  ]
}
```
