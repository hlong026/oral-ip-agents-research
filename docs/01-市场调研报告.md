# 口播IP智能体市场调研报告

- 调研时间：2026 年 7 月
- 调研范围：旗博士、罗根、轻语、茄条AI、AIPGPT、淘金AI、Deepshow、夜神AI，以及蝉镜/闪剪/腾讯智影/讯飞智作等大厂参照产品
- 调研方法：公开资料分析（官网、GitHub、CSDN/知乎评测、淘宝/闲鱼在架商品、抖音/小红书搜索结果）

---

## 1. 赛道概述

### 1.1 什么是"口播IP智能体"

口播IP智能体是一类面向**自媒体个人 IP、企业品牌、电商卖家、MCN 矩阵运营者**的 AI 工具，核心卖点是"**不出镜、不写稿、不剪辑，一键批量产出口播短视频**"。其标准流水线为：

```
对标视频链接/选题 → 文案提取(ASR) → 文案仿写(LLM) → 声音克隆(TTS)
→ 数字人口播(形象克隆/唇形驱动) → 字幕/BGM/标题/封面(FFmpeg)
→ 多平台自动发布(抖音/视频号/小红书/快手)
```

### 1.2 市场驱动因素

- **供给侧**：开源模型成熟（Whisper、CosyVoice、GPT-SoVITS、HeyGem、Wav2Lip、EchoMimic），整合门槛低，大量小团队可快速拼装产品。
- **需求侧**：个人 IP 创业、本地生活获客、企业老板 IP、电商带货对"低成本日更口播视频"需求旺盛；"一个人就是一支内容军队"是统一营销话术。
- **平台侧**：抖音/视频号/小红书对数字人内容从限制转向规范（AI 内容标识），合规化工具存在窗口期。

### 1.3 产品形态分类

| 形态 | 代表产品 | 特征 |
| --- | --- | --- |
| 本地买断工具 | 旗博士、茄条AI | Windows 本地客户端，吃显卡，一次性买断 ¥299–¥899 |
| 云端 SaaS | 罗根、淘金AI、蝉镜、闪剪 | 网页/小程序使用，订阅或买断+算力续费 |
| 混合双算力 | 轻语 IP 智能体 | 本地免费 + 赠送云算力，全终端覆盖 |
| 企业私有化/平台型 | Deepshow、AIPGPT | 源码交付/多智能体协同，客单价高 |
| 开源引流 + 私域转化 | 旗博士 GitHub、罗根 LuoGen-agent-plus | GitHub 公开"工程框架"，引流到微信成交 |

## 2. 重点产品深度分析

### 2.1 旗博士口播智能体（QiboShi）

**一句话定位**：本地运行、模块化的 AI 数字人口播视频自动化生成工具，创舰科技出品，入门级爆款。

#### 平台分布

| 渠道 | 情况 |
| --- | --- |
| GitHub | 以 `KrLongAI` 等仓库公开工程 README 引流（标注"商业级应用"） |
| 抖音 | "旗博士（创舰科技）""祁博士（AI创舰学院）"等账号矩阵，搜索"旗博士口播智能体怎么用"有大量教程/带货视频 |
| 淘宝/闲鱼 | "轻语超级ip口播智能体爆款ai数字人…旗博士罗根"等关键词商品，官方价 ¥799–¥899，盗版/共享版 ¥6.8–¥299 |
| 互站网等源码站 | "ip口播智能体手机版爆款ai数字人一键生成口播短视频旗博士罗根"源码/成品转售 |
| 微信私域 | README 留微信号成交，9.9 元试用 → 799/899 元买断 |

#### 功能模块构成

1. 对标文案提取（粘贴爆款视频链接 → 下载视频 → ASR 转文字）
2. 文案仿写（语义级仿写与结构重组）
3. 声音克隆 / 语音合成
4. 数字人口播生成（唇形同步）
5. 字幕生成、背景音乐、视频标题、封面生成
6. 多平台发布（抖音、视频号、快手、小红书）
7. 本地客户端（统一控制流水线）

#### 业务逻辑

- 以"爆款复刻"为核心场景：用户不提供创意，而是复制已有爆款 → 仿写去重 → 换自己的数字人重新演绎 → 批量分发吃平台流量。
- 本地运行 = 用户自备算力，厂商边际成本接近零，所以敢做"买断制"；隐性成本转嫁给用户（低配电脑跑不动需租高配云电脑，是被评测点名的"隐性消费"）。
- 硬性要求万元级高配 PC + 高端独显，仅支持 Windows。

#### 技术实现

| 模块 | 技术方案 |
| --- | --- |
| 语音识别 ASR | Whisper（开源） |
| 语音合成/克隆 | CosyVoice（开源） |
| 数字人驱动 | HeyGem（开源数字人） |
| 视频合成 | FFmpeg |
| 多平台发布 | 平台 API / social-auto-upload（开源自动上传） |
| 架构 | 本地模块化工程：`script/ audio/ avatar/ video/ uploader/ client/`，各模块解耦可替换 |

本质：**开源组件的工程整合 + 流程自动化**，而非自研模型。

#### 商业模式

- 买断授权 ¥899（活动价 ¥799），9.9 元试用引流
- 终身免费更新；通过抖音直播演示 + 广告投流获客
- 被竞对评测指出的软肋：广告预算大、演示用高配机、用户低配体验落差大、需额外租云电脑

### 2.2 罗根智能体 / 罗根口播智能体（LuoGen）

**一句话定位**：基于自研轻量级 Agent 框架 LuoGen-agent-plus 的云端全链路口播视频方案，售价最高（¥1999）。

#### 平台分布

| 渠道 | 情况 |
| --- | --- |
| GitHub | `LuoGen-AI-Plus/LuoGen-agen-plus` 开源 Agent 框架引流 |
| CSDN/脑启社区 | 大量软文（"罗根口播智能体：IP 口播获客必备神器"），附百度网盘试用包 |
| 抖音 | "罗根智能体发布平台"等搜索词，教程类内容 |
| 淘宝/闲鱼 | 与旗博士捆绑关键词销售，盗版泛滥 |
| 微信小程序 | 三款竞品中唯一支持小程序端 |
| 客户端 | Windows 客户端（不支持 Mac/移动端 App） |

#### 功能模块构成（官方口径 8 大模块）

1. **文案生成**：仿写模式选择、自定义指令仿写；API KEY 管理
2. **音频生成**：音色刷新、语速调节（推荐 0.8–1.2）
3. **视频生成**：专属数字人训练（上传参考视频训练 IP 数字人）+ 免训练数字人生成；AI 对口型；高级参数设置；预览与案例
4. **字幕生成**：字号、底边距（默认 60px）、字体颜色
5. **背景音乐**：自动 BGM / 自定义 BGM / 无 BGM 三模式
6. **标题生成**：自动标题 + 话题标签
7. **封面制作**：自定义封面、一键添加
8. **多平台发布**：抖音、视频号、小红书一键发布（保持账号登录态），商业版更完善

#### 业务逻辑

- 云端全托管：低配电脑也能用（3000 元办公机即可），但**绑定云算力续费**——买断 ¥1999 仅含 1.5 年云端算力，长期续费成本高，是典型的"低门槛进、高留存收费"逻辑。
- 同时把框架开源（LuoGen-agent-plus）做开发者生态与 SEO/获客，软件本体收费。

#### 技术实现

- 四层架构：**配置层**（YAML/JSON 定义 Agent 角色/能力/规则）→ **核心层**（意图识别、任务规划、工具选择、结果生成）→ **工具层**（工具注册/调用/权限管控）→ **交互层**（CLI、HTTP API、WebSocket）
- 多智能体协作："主 Agent + 子 Agent"分层，支持 IP 矩阵批量生成
- 多模态：文本/语音/图片输入输出，对接主流大模型
- Python 3.8+，pip 安装即可本地开发；运行时依赖云端服务器

#### 商业模式

- 买断 ¥1999（含 1.5 年云算力），后续算力续费为主要持续收入
- 商业版分级（发布等功能更完善）
- 开源框架引流 + 软文矩阵（CSDN 系）+ 私域成交

### 2.3 轻语 IP 智能体（轻语科技）

**一句话定位**：全终端（Win/Mac/iOS/Android）+ 本地/云端双算力的口播IP工具，¥799 买断，杭州轻语科技（2018 年成立）出品，10 万+ 用户。

#### 平台分布

| 渠道 | 情况 |
| --- | --- |
| 官网 | qingyu.club，完整产品页/帮助文档（飞书知识库）/更新日志 |
| 客户端 | Windows 10+、macOS 11+、iOS、Android（四端，是竞品中唯一全覆盖） |
| 抖音/小红书 | "轻语IP智能体"教程与评测内容；竞对对比文常以其为性价比标杆 |
| 淘宝/闲鱼 | 官方旗舰店式商品（¥799），同时被盗版蹭词 |
| 私域 | 助教老师 1v1、7×16 小时真人客服 |

#### 功能模块构成（官网 6 大模块）

1. **形象管理**：人设档案管理、风格锁定、多账号形象独立维护（解决"账号精神分裂"）
2. **数字人中心**：专属数字分身、一次生成永久使用、微表情、多套形象
3. **声音克隆**：5 分钟录音克隆、音色还原与情感、多音色管理
4. **一键出视频**：粘贴抖音/小红书链接 → AI 改写文案 → 克隆声音 → 驱动数字人 → 剪辑匹配素材 → 封面标题，最快 10 秒成片
5. **素材管理**：素材库语义分析、按文案精准匹配混剪、批量处理（矩阵必备）
6. **账号管理与自动发布**：多账号统一管理、定时自动发布、多平台同步分发

#### 业务逻辑

- **双算力架构**：本地算力永久免费离线可用 + 赠送 2 年云算力，不限生成次数/时长——直接攻击旗博士（无云算力、吃显卡）与罗根（纯云端、续费贵）的软肋。
- 配套"工具 + 课程 + 服务"：每款工具配系统课程，教用户变现；真人客服多对一。
- 产品矩阵：轻语IP智能体（视频）+ 红薯侠（小红书图文）+ 更多垂直智能体，做创作者工具全家桶。

#### 技术实现

- 大语言模型驱动的人设定位与脚本生成；AIGC + 语音克隆 + 数字人驱动封装为极简操作
- 本地 + 云端混合调度（低配机可流畅运行本地模块）
- 四端客户端（推断为跨端框架 + 云端渲染兜底）

#### 商业模式

- 买断 ¥799，无隐性消费（主打卖点）
- 课程/陪跑变现；客服与助教人力服务提升口碑与转介绍
- 矩阵产品交叉销售（红薯侠等）

### 2.5 AIPGPT（天空十方·上海）

**一句话定位**：企业级"AI 驱动的品牌 IP 全域增长引擎"，27 位数字员工多智能体协作，从营销策略到销售转化闭环。

#### 平台分布

- 官网 aipgpt.cn（预约演示制）；iOS App；Hugging Face 开源自研润色模型（"推理+常规"双模型，业界首个短视频创作领域润色模型）

#### 功能模块构成

1. **AI 策划大师**：深度学习优质 IP 成功逻辑，IP 人设模型（亿级操盘手起号公式，**81 个策划字段**生成 IP 策划案）
2. **专属选题推荐**：基于策划案 + 实时热点 + 商业变现需求推荐选题
3. **AI 文案创作**：多专家模型协同（选题→大纲→成稿），强化学习 + 传播力优化算法（宣称播放量提升 300%）
4. **AI 语音生成**：声音大模型、情绪识别与匹配
5. **AI 视频生成**：数字人全场景（站姿/坐姿/绿幕/室外/走动），一次拍摄解锁海量视频
6. **IP 个人知识库**：自研 Graph-RAG 知识图谱，构建专属 AI 大脑，可**绑定对标账号实时学习**
7. **智能体组织架构**：27 位数字员工 7×24 协作（策划、创作、转化）

#### 业务逻辑

- 不做"一键出片工具"，做"AI 内容团队"：策略层（人设/选题）→ 生产层（文案/语音/视频）→ 资产层（知识库），目标客户是品牌企业与规上企业。
- 开源自研润色模型做技术品牌与获客。

#### 技术实现

- 自研推理引擎 + 强化学习润色模型（HF 开源）
- Graph-RAG 知识图谱；多智能体编排；声音大模型；数字人多场景驱动

#### 商业模式

- 预约演示 → 企业方案报价（AIP 标准产品 / 企业品牌虚拟 IP / IP 营销策划服务 / 企业 AI 部门落地 / 规上企业解决方案）
- 渠道及商务合作；高客单、重交付

## 5. 销售渠道与用户旅程分析

### 5.1 典型获客漏斗

```
抖音/小红书/视频号 教程&效果演示（钩子："不出镜日更10条"）
  → 评论区/私信引导加微信
  → 9.9 元试用 / 免费网盘体验包
  → 799–1999 元买断成交
  → 课程/陪跑/代理二次变现
```

### 5.2 各平台角色

| 平台 | 角色 |
| --- | --- |
| 抖音 | 主获客场：效果演示、直播带货（高配机演示）、SEO 搜索词（"XX智能体怎么用"） |
| 小红书 | 副业/创业人群种草，"AI 搞钱"笔记 |
| 视频号 | 中老年/实体商家获客，私域导流 |
| 淘宝/闲鱼 | 成交场 + 盗版泛滥地（¥6.8–¥299 共享版/破解版，同时蹭"旗博士罗根"关键词） |
| GitHub/CSDN/知乎 | 技术背书 + SEO + 开发者引流 |
| 微信 | 最终成交与售后服务场 |

### 5.3 用户核心痛点（来自评测与商品评价）

1. 低配电脑跑不动本地模型（旗博士最大槽点）
2. 云端续费贵（罗根最大槽点）
3. 数字人形象/声音"一眼 AI"，被平台限流
4. 自动发布接口不稳定（平台风控升级导致上传失效）
5. 内容同质化 → 账号被判搬运/低质
6. 盗版横行，正版服务价值被稀释

## 6. 市场机会与启示（对我们产品的输入）

1. **算力架构是定价权核心**：轻语"本地免费 + 赠云算力"模式验证了双算力的竞争力；我们应做**智能混合调度**（本地够用走本地，不够用云端兜底，按量透明计费）。
2. **全终端是被验证的差异化**：竞品仅轻语覆盖四端；移动端"随手复刻爆款"是高频场景。
3. **从"工具"升级到"IP 资产管理"**：人设档案、声音/形象资产库、知识库（Graph-RAG）、对标账号学习，目前只有 AIPGPT 做深，个人价位段空白。
4. **合规与风控是下一个竞争点**：违规审核（Deepshow 独有）、AI 内容标识适配、平台规则跟进，将决定工具的生存周期。
5. **矩阵运营是付费意愿最强的场景**：多账号管理、定时发布、数据回流分析，是 MCN 与工作室的刚需。
6. **商业模式组合**：买断 + 算力订阅 + 课程 + 代理 + 企业定制，多层变现；用开源/免费版做获客漏斗顶层。
