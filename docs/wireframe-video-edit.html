断点清单

按影响程度排序；后端 compose → edit → recompose 契约与实现均已核实无误。

  • A
    向导状态丢失，第6步可能空态

    合成任务创建后 replace 跳转到 /tasks/:id，CreatePage 卸载后 wiz.taskId 不持久化；用户回到 ?step=edit 时无成片预览。

    体验断裂
  • B
    去剪辑台不带任务上下文

    StepEdit 跳转 /editor 未携带 ?task=，剪辑台默认选中已完成任务列表第一个，不一定是当前向导任务。

    上下文断链
  • C
    向导第6步为占位，未接剪辑接口

    向导内无字幕/封面/BGM 配置，也不调用 recompose；真实剪辑能力全部在独立剪辑台页面。

    功能占位
  • D
    BGM 前端刻意封死

    后端完整支持 bgm_key / bgm_mode / bgm_volume，前端类型硬编码 bgmMode: "off"（版权归属未就绪），构成能力断层。

    能力闲置
  • E
    三画幅未暴露

    后端 ratio 支持 9:16 / 16:9 / 1:1，前端无画幅选择入口，始终走默认 9:16。

    能力闲置
  • ✓
    已确认无问题项

    edit 步已注册于 STEP_RUNNERS；产物字段命名一致；剪辑台已接真实接口，含计费确认、幂等键与版本冲突处理，无 Mock 残留。
