# 第二阶段真实链路验收

第二阶段的代码检查不能替代真实供应商和真实平台验收。本验收脚本固定使用一条真实平台链接和一段仓库内正文，各连续运行至少 3 次，保存 HTTP 交换、步骤耗时、积分、MP4、`ffprobe` 结果和完整人工发布包。

## 前置条件

- API、Dramatiq Worker、Redis、数据库和对象存储均已启动。
- 生产 Provider 已配置且启用；生产环境不会回退 Mock。
- 测试账号有有效套餐和足够积分，IP、声音、数字人资产均为 `ready`。
- 如需通过“真实发布”退出条件，目标平台须先用真实账号验收，并加入服务端 `PUBLISH_VERIFIED_PLATFORMS`。
- 本机可执行 `ffprobe`。

## 执行

访问令牌只通过环境变量传入，脚本不会把令牌写入证据文件：

```bash
export STAGE2_ACCESS_TOKEN='...'
export STAGE2_IP_ID='...'
export STAGE2_VOICE_ID='...'
export STAGE2_AVATAR_ID='...'
export STAGE2_REAL_LINK='同一条真实抖音或小红书链接'
export STAGE2_PLATFORM='douyin'

cd server
uv run python scripts/stage2_acceptance.py
```

证据默认写入仓库根目录的 `evidence/stage2/<UTC 时间>/`，该目录已加入 `.gitignore`。脚本退出码含义：

- `0`：两类固定输入各连续至少 3 次生成合格 MP4，且所选平台有真实发布成功记录；完整发布包也已验证。
- `1`：成片、计费、媒体探测、发布包或 API 链路失败。
- `2`：成片和发布包通过，但没有本轮真实账号发布成功证据；不能据此宣称第二阶段完全退出。

## 证据结构

- `manifest.json`：固定输入及其 SHA-256，证明多次运行没有换样本。
- `http/*.json`：脱敏后的请求、响应、状态码和请求耗时。
- `runs/<输入>-<次数>/final.mp4`：实际成片。
- `runs/<输入>-<次数>/ffprobe.json`：编码、分辨率、时长和文件大小。
- `runs/<输入>-<次数>/*.zip`：视频、封面和 `metadata.json` 完整发布包。
- `summary.json`：步骤 Provider、步骤耗时、报价/结算积分、发布结果和未闭环阻塞项。
